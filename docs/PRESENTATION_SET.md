# 产品概念展示图三件套

按项目指定的 iF 2027 三件套规格制作，不表示已核实主办方当年规则。

1. 冻结当前概念，生成并确认对应产品效果图。
2. 在 1C 点击“生成产品概念展示图”。使用当前图片模型，必须支持参考图输入；三次生成均引用同一产品图与同一冻结快照。
3. 分别查看横版 WHY + WHAT + Hero Scene、竖版 HOW / 结构 / 交互、Poster 的六项信息。核对三张产品及字体一致；Poster 场景主图须超过全版 50%，冻结例外除外。
4. 勾选一致性核对后，可下载三张独立 JPG 或 ZIP。

横版 4750×3167 px，竖版 3167×4750 px；Poster 8400×4300 px、JFIF 254 dpi，对应 840×430 mm。三张均通过 sRGB Canvas 编码为 JPG，每张上限按 5,000,000 字节检查。通过逐级降低 JPEG 质量满足上限，不改变像素尺寸；标题由同一字体统一排入。

三张是独立生成构图，不使用同图裁切。提示词禁止重新设计、iF logo 与 SDG。像素、编码和大小由程序控制；产品细节、标识以及场景面积需要人工核对，不能仅凭生成成功认定视觉一致。冻结/外观/产品名改变会禁用旧成果下载。生成中途失败或取消不覆盖上一套完整成果。

固定演示只验证链路，不验证真实模型遵循提示词的能力。浏览器回归检查三张预览、JPG 下载及尺寸/体积。
